# Analysis Results Directory

This directory contains all analysis results from various experiments.

## Subdirectories

- `augmentation_results/` - Results from data augmentation experiments
- `erasing_method/` - Results from erasing method analysis
- `feature_ablation/` - Feature ablation study results
- `model_results/` - Model performance and evaluation results
- `statistical_relevance/` - Statistical relevance analysis results
- `statistical_relevance_block/` - Block-wise statistical relevance results
- `tsne_results/` - t-SNE visualization and clustering results

**Note**: All result files are may have been excluded from git due to large file sizes. Please refer to the corresponding analysis notebooks to regenerate the results.
